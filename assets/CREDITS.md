# Asset credits

Third-party assets of Retreat Arena, with their licenses. Every file added under `assets/` that we
did not make ourselves must be listed here. The CC BY 4.0 parts require these credits to travel with
the game.

## models/Fox.glb

From the Khronos glTF Sample Assets:
https://github.com/KhronosGroup/glTF-Sample-Assets/tree/main/Models/Fox

- Model: PixelMannen, 2014, CC0 1.0 (https://creativecommons.org/publicdomain/zero/1.0/)
- Rigging and animation: tomkranis, 2014, CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/)
- Conversion to glTF: @AsoboStudio and @scurest, 2017, CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/)

Unmodified file (the same one the engine sandbox uses). The game tints it with each player's color.
